# 闪光覆盖与淡出

## 设置

在「实用功能 → 自定义闪光效果 → 设置」调整「淡出时长」，范围为无淡出～2.0 秒，步长为 0.1 秒，默认 1.0 秒。拖动松开后保存，键盘和点击调整也会保存；重启保留。可点击「恢复默认淡出」回到 1.0 秒，旧配置缺少此设置时也使用 1.0 秒。

时长控制闪光结束后覆盖图片消失的速度：短一些更快露出游戏，长一些过渡更缓。所有档位先等待约 60 ms 确认恢复，减少短暂回跳；无淡出在确认后直接撤去覆盖。开始被闪时仍立即覆盖。正在淡出时修改时长，新值用于下一次恢复，避免当前透明度突然跳变。

程序自动读取覆盖窗口所在屏幕的刷新率，切换屏幕和刷新率变化时更新调度间隔。当前精确定时器间隔限制为 4～16 ms，60/120/144/165/240 Hz 分别约为 16/8/7/6/4 ms。这是动画调度目标，不是垂直同步或实际帧率保证。屏幕缩放比例变化时，从同一张保留原图更新物理像素缓存；正在淡出时不切换随机图片。无需手动匹配按钮。

## 延迟优化与测量

闪光图片预先缩放到覆盖窗口的物理像素尺寸，并与深色背景合成缓存。开始覆盖时优先处理视觉状态并立即重绘，淡出直接绘制同一缓存，避免每帧生成全窗口透明度中间图。透明区和等比例留白也参与覆盖及淡出。

2026-10-14 的测量使用生成的 1254×1254 非纯色图片、本地 HTTP 模拟 GSI、Qt 排队信号和离屏同步重绘。各分辨率预热 10 次后测量 120 次，从完整接收模拟请求体到同步重绘返回结束，并确认实际发生绘制。单位：毫秒。

| 覆盖尺寸 | 优化前中位值 | 最终源码中位值 | 最终源码 P95 |
| --- | ---: | ---: | ---: |
| 1920×1080 | 4.685 | 0.714 | 0.932 |
| 2560×1440 | 5.267 | 1.233 | 1.876 |

默认 1 秒淡出的实际 Qt 定时恢复测量使用 1707×960 逻辑尺寸、150% 缩放及 165 Hz 调度目标。半透明阶段实际绘制 93 次，绘制间隔中位值 10.517 ms、P95 12.548 ms。收到恢复至完全透明约 1069.076 ms，包含约 60 ms 确认。透明度单调下降，最终 alpha 为 0。早期恢复基线对应 38 次绘制和 26.285 ms 的中位间隔。

测量不包含游戏发送 GSI 前的延迟、Windows 合成器和显示器呈现，也未测量屏幕实际亮度响应。独立测量存在运行波动，这些值不能解释为最坏情况上限、游戏端到端延迟或零瞬间白光保证。

## 验证

功能完成时，89 项回归测试及 150% 缩放下 22 项闪光过渡/设置测试通过，包括设置保存与重启、旧配置及导入边界、无淡出、当前动画时长稳定、不同刷新率、屏幕切换、再次被闪、最终完全透明和图片稳定。测试使用临时配置和生成图片。

实现使用外部 GSI 和 Qt 覆盖，没有加入游戏注入、内存访问或反作弊绕过。具体发布包的构建及最终验证状态见对应 GitHub Release。
